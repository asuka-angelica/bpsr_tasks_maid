# スタレゾ日課メイド（仮称）

スタレゾ（Blue Protocol: Star Resonance）の毎日／毎週／2週間ごとの用事を、デスクトップ常駐のメイド（モモ）がチェックリストで出してくれて、片付けるたびに褒めてくれるアプリ。設計書は `~/workspace/starezo-maid-checklist/DESIGN.md` が正本。

## フェーズ0 の範囲

- チェックリスト（プリセット同梱）＋周期リセット（毎日5:00／毎週 月曜5:00／2週間ごとはアンカー日＋5:00）
- 数値管理（ボス鍵・精鋭鍵・フォーカス：境界で自動回復、手動で消費）
- 右端ドックの3態（最小化＝アイコンのみ／待機（ミニ）＝細い縦バー／展開＝メインパネル）。ホバーかクリックでミニ→展開、戻す操作はヘッダーのボタン
- キャラ表示（モモ、動画クリップ再生：挨拶→待機ループ／チェックで褒める。展開では等身クリップ、待機（ミニ）では SD クリップ）＋吹き出し台詞（ボイスはフェーズ1）
- 設定（呼び方の初回選択・変更、項目ごとの通知オン／オフ＝保存のみ、キャラ選択、エージェント表示オン／オフ＝オフでは管理機能のみ）

データはローカルJSONのみで、外部送信は一切しません。ゲーム本体の読み取り・自動操作もしません（手動チェック式）。

## 開発

```
npm install
npm test        # 純粋ロジックの単体テスト（node --test）
npm start       # Electron で起動
```

Windows 配布ビルドは `build-windows.bat`（electron-packager）。

## ボイスパックの追加（任意）

アプリ本体に音声は同梱していません。手元の音声ファイルを置くと、挨拶・褒め・全完了の場面でボイスが鳴るようになります。

- 置き場所：アプリのデータフォルダ（Windows では通常 `%APPDATA%\bpsr-tasks-maid`）直下に `voice` フォルダを作り、その中に入れます
- フォルダ構成：`voice/<キャラID>/<場面>.<拡張子>`
  - キャラID：`momo`（モモ）／`suzuran`（スズラン）／`mimoza`（ミモザ）
  - 場面：`greeting`（挨拶）／`praise`（褒め）／`complete`（全完了）
  - 拡張子：`mp3` または `wav`（両方ある場合は `mp3` が優先されます）
  - 例：`voice/momo/greeting.mp3`、`voice/suzuran/praise.wav`
- 検出方法：アプリは起動のたび（状態取得のたび）に `voice` フォルダの有無と中身を自動で確認します。フォルダが存在する環境でのみ、設定画面にボイスのオン／オフ項目が表示されます。フォルダが無ければボイス関連の表示は一切出ません。ファイルを置いたらアプリを開き直すだけで反映されます
- 音声素材を使う場合は、その素材の利用条件（クレジット表記や事前相談など）に従ってください

## 構成

- `main.js` / `preload.js` — Electron の土台。レンダラーはカスタムスキーム `maid://` で配信
- `src/` — 純粋ロジック（周期計算・数値回復・状態遷移・プリセット・台詞）と保存層
- `renderer/` — 画面（単一画面・スクロールなし、一覧のみ内部スクロール）
- `test/` — 単体テスト
- `docs/PLACEHOLDERS.md` — プレースホルダ台帳（後で Codex に発注するアイコン等の差し替え先）
