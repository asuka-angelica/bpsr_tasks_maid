# スタレゾ日課メイド（仮称）

スタレゾ（Blue Protocol: Star Resonance）の毎日／毎週／2週間ごとの用事を、デスクトップ常駐のメイド（モモ）がチェックリストで出してくれて、片付けるたびに褒めてくれるアプリ。

> **本アプリは非公式のファンメイドツールです。** ゲーム『Blue Protocol: Star Resonance』公式（バンダイナムコ／開発元）とは関係ありません。ゲーム本体のデータや公式素材は含んでいません。

## 同梱素材の出所

- モモ／スズラン／ミモザの静止画・動画クリップ・アプリアイコンは、開発側が **AI 生成したオリジナル素材** です（キャラクターシートを ChatGPT で生成し、静止画・動画・アイコンを Codex の生成経路で制作しました）。ゲームの公式素材や第三者のイラストは含んでいません
- 音声（ボイス）は同梱していません。ボイスパックの追加方法と利用条件は「ボイスパックの追加」を参照してください
- 追加キャラの素材の権利については「キャラ設定パッケージ」の注記を参照してください

## フェーズ0 の範囲

- チェックリスト（プリセット同梱）＋周期リセット（毎日5:00／毎週 月曜5:00／2週間ごとはアンカー日＋5:00）
- 数値管理（ボス鍵・精鋭鍵・フォーカス：境界で自動回復、手動で消費）
- 右端ドックの3態（最小化＝アイコンのみ／待機（ミニ）＝細い縦バー／展開＝メインパネル）。ホバーかクリックでミニ→展開、戻す操作はヘッダーのボタン
- キャラ表示（モモ／スズラン／ミモザ＋追加キャラ対応。動画クリップ再生：挨拶→待機ループ／チェックで褒める。展開では等身クリップ、待機（ミニ）では SD クリップ。立ち絵＋表情差分形式も選択可）＋吹き出し台詞
- 設定（呼び方の初回選択・変更、項目ごとの通知オン／オフ＝保存のみ、キャラ選択、エージェント表示オン／オフ＝オフでは管理機能のみ）

データはローカルJSONのみで、外部送信は一切しません。ゲーム本体の読み取り・自動操作もしません（手動チェック式）。

ライセンスは MIT License です（`LICENSE` を参照）。同梱素材の扱いについては「同梱素材の出所」もあわせてご覧ください。

## 開発

```
npm install
npm test        # 純粋ロジックの単体テスト（node --test）
npm start       # Electron で起動
```

Windows 配布ビルドは `build-windows.bat`（electron-packager）。

## キャラクターの追加（任意）

モモ・スズラン・ミモザ以外のキャラ（メイド以外でも可）を追加できます。追加したキャラは設定画面のキャラ選択に現れ、台詞・呼び方・ボイスも含めて同じように動きます。

### 設定画面から登録する（推奨）

1. 設定画面の「キャラクター追加」を開きます
2. 名前と表示形式を選びます
   - **アニメーション（動画）**：場面ごとのクリップで動きます。対応拡張子は **mp4 / webm**
   - **立ち絵（＋表情差分）**：基本の立ち絵＋場面ごとの表情差分画像を切り替えます。対応拡張子は **png / jpg / webp**
   - **Live2D**：モデル（`*.model3.json`）を登録できます。**現在は登録・検出・選択までの対応で、再生は未対応です**（画面にもその旨が表示されます）
3. 台詞（挨拶／褒め／全完了）を1行に1台詞で入力します。台詞中の `{address}` は呼び方に置き換わります
4. 呼び方の候補と既定の呼び方（任意）を入力します。表示中のキャラの呼び方は、設定画面の「（キャラ名）の呼び方」でも後から変更できます（優先順位：キャラごとの設定 > キャラ定義の既定 > 全体設定 > ご主人様）
5. 形式ごとの素材ファイル（モーション／表情差分／モデル）と、任意でボイス（mp3 / wav）を選びます
6. 「このキャラを登録する」を押します。登録内容はデータフォルダの `characters/<キャラID>/` に定義ファイル（`character.json`）＋素材として保存され、再起動後も残ります

### キャラ設定パッケージ（他の人へ渡す）

- 設定画面の「キャラ設定パッケージ」から、表示中のキャラの定義＋素材一式を zip で**書き出し**できます
- 受け取った人は同じ場所の「読み込み」から zip を選ぶだけで、そのまま登録できます（同じIDのキャラが既にある場合は読み込めません）
- キャラ素材の権利や二次配布は、そのキャラを作成・配布した人の責任であり、このアプリは登録・表示の仕組みを提供するものです

### フォルダを直接置く方法（上級者向け）

データフォルダ直下の `characters/` に、キャラごとのフォルダ＋ `character.json` を置いても追加できます（アプリは状態取得のたびに走査するので、置くだけで選択肢に現れます）。

- フォルダ構成：`characters/<キャラID>/character.json` ＋ 素材ファイル（同じフォルダに平置き）
- `character.json` の主な項目：
  - `name`：表示名、`type`：`video` / `image` / `live2d`
  - `lines`：`{ "greeting": [...], "praise": [...], "complete": [...] }`（各1つ以上必須）
  - `address`（任意）：`{ "candidates": [...], "default": "…" }`
  - 動画形式：`clips`：`{ "idle", "greeting", "praise", "sdIdle"?, "sdJump"? }`（ファイル名を指定）
  - 立ち絵形式：`images`：`{ "idle", "greeting", "praise", "complete", "sdIdle"?, "sdJump"? }`
  - Live2D形式：`model`：モデルファイル名（`*.model3.json`）
- 定義に問題があるキャラは読み込まれず、設定画面に理由が表示されます

## ボイスパックの追加（任意）

アプリ本体に音声は同梱していません。手元の音声ファイルを置くと、挨拶・褒め・全完了の場面でボイスが鳴るようになります。キャラ登録時にボイスも一緒に登録できます（下記と同じ場所に保存されます）。

- 置き場所：アプリのデータフォルダ（Windows では通常 `%APPDATA%\bpsr-tasks-maid`）直下に `voice` フォルダを作り、その中に入れます
- フォルダ構成：`voice/<キャラID>/<場面>.<拡張子>`
  - キャラID：`momo`（モモ）／`suzuran`（スズラン）／`mimoza`（ミモザ）、および追加したキャラのID
  - 場面：`greeting`（挨拶）／`praise`（褒め）／`complete`（全完了）
  - 拡張子：`mp3` または `wav`（両方ある場合は `mp3` が優先されます）
  - 例：`voice/momo/greeting.mp3`、`voice/suzuran/praise.wav`
- 検出方法：アプリは起動のたび（状態取得のたび）に `voice` フォルダの有無と中身を自動で確認します。フォルダが存在する環境でのみ、設定画面にボイスのオン／オフ項目が表示されます。フォルダが無ければボイス関連の表示は一切出ません。ファイルを置いたらアプリを開き直すだけで反映されます
- 音声素材を使う場合は、その素材の利用条件（クレジット表記や事前相談など）に従ってください

## 構成

- `main.js` / `preload.js` — Electron の土台。レンダラーはカスタムスキーム `maid://` で配信
- `src/` — 純粋ロジック（周期計算・数値回復・状態遷移・プリセット・台詞）と保存層
- `renderer/` — 画面（単一画面・スクロールなし、一覧のみ内部スクロール）
- `test/` — 単体テスト
- `docs/PLACEHOLDERS.md` — プレースホルダ台帳（簡易素材で置いた箇所と差し替え先の記録）
